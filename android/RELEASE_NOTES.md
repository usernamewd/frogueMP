# Android APK Build Release Notes

## Version 1.0.1a (Build 3)
**Release Date:** December 12, 2025

### Build Information
- **Package:** io.github.necrashter.natural_revenge
- **Target SDK:** 35 (Android 15)
- **Minimum SDK:** 19 (Android 4.4)
- **Architecture Support:** ARM64, ARMv7, x86, x86_64
- **Build Type:** Release with ProGuard minification

### Features Included
- Multiplayer game functionality
- Mobile-optimized controls
- Cross-platform compatibility
- Advanced graphics rendering
- Network multiplayer support
- Touch controls for mobile devices

### Technical Details
- **MultiDex:** Enabled for large app size
- **ProGuard:** Enabled for code obfuscation and size reduction
- **Native Libraries:** All architectures supported
- **Assets:** Optimized game assets included

### Build Environment
- **LibGDX Version:** Latest stable
- **Gradle:** Wrapper included
- **Java:** JDK 8+ required
- **Android SDK:** API 19+ (targeting API 35)

### Installation
1. Enable "Unknown Sources" in Android settings
2. Download and install the APK
3. Launch the app and enjoy!

### File Size
- **Estimated APK Size:** ~25-30 MB
- **Compressed Assets:** Yes
- **Native Libraries:** Included for all supported architectures

### Notes
This build represents the complete Android implementation of the Frogue game engine with multiplayer capabilities. The build process requires Android SDK and Java JDK to be properly configured on the build machine.
